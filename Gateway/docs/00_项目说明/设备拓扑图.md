## 树2：纯 DTU 树（DTU_010 为 root）

树2由 60 个 DTU 组成，节点范围为 `DTU_010` 到 `DTU_069`，不挂载外接设备，只作为 SLE 树形组网和中继节点展示。树2的父子关系以 root 上报的 ST `0x05` 拓扑快照为准。

```
DTU_010 (root)
├── DTU_011
├── DTU_012
├── DTU_013
├── ...
└── DTU_069
```

## 配置与在线判定

- `gateway_config.json` 中的 DTU 条目只表示全量 DTU inventory，每个条目必须包含 `device_id`、`type=dtu_node`、`node_id`。
- 正式 `root_report` 模式下，JSON 不保存 DTU 父子关系，也不保存外接设备静态挂载关系。
- DTU 在线状态只由最新有效 ST `0x05` 拓扑快照决定。
- 外接设备在线状态只由 ST `0x06` 键值映射和对应 DTU 是否在线共同决定。
- root 节点列表由 `sle.roots` 配置，本拓扑当前为 `DTU_001` 和 `DTU_010` 两路 root。

## 数据流

```
RS485设备 → DTU节点(采集) → DTU网关(MQTT上报) → ThingsKit平台
```

## MQTT Topic

| Topic | 用途 |
|-------|------|
| v1/devices/me/attributes | 网关属性 |
| v1/gateway/connect | 子设备上线通知 |
| v1/gateway/telemetry | 子设备遥测（DTU代发） |
