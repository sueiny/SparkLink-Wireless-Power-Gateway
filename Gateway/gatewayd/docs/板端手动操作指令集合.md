# 板端手动操作指令集合

> Status: Current board-operation command reference.
> Authority: 常用 ADB、driver.sh、日志查看和上下行排查命令以本文为入口。
> Superseded by: None.
> Last verified against: `app/Gateway/.claude/skills/run-gateway/driver.sh` on 2026-06-28.

本文整理 Gateway 板端联调时最常用的手动命令，适用于需要频繁执行：

- 推送最新配置或应用。
- 重启 `gatewayd + sle_data_app --mode real`。
- 打开 SLE 串口链路监听助手。
- 查看 gateway、SLE、上下行、网络和 MQTT 状态。

默认仓库根目录：

```bash
cd /home/sueiny/rk3506_linux6.1_v1.2.0
```

## 一步到位主流程

最常用：编译/推送最新 app 和配置，重启真实 Gateway 链路，并进入 SLE 专用监听。

```bash
bash app/Gateway/.claude/skills/run-gateway/driver.sh build-sle
bash app/Gateway/.claude/skills/run-gateway/driver.sh build-gw
bash app/Gateway/.claude/skills/run-gateway/driver.sh push
bash app/Gateway/.claude/skills/run-gateway/driver.sh restart-real-watch
```

如果只改了 `gateway_config.json`，不需要重新编译：

```bash
adb push app/Gateway/gatewayd/config/gateway_config.json /userdata/gateway/config/
bash app/Gateway/.claude/skills/run-gateway/driver.sh restart-real-watch
```

如果二进制和配置都已经在板端，只想重启并监听：

```bash
bash app/Gateway/.claude/skills/run-gateway/driver.sh restart-real-watch
```

## 三条核心指令

### 1. 推送最新应用与配置

```bash
bash app/Gateway/.claude/skills/run-gateway/driver.sh push
```

`push` 会推送：

- `/userdata/gateway/bin/gatewayd`
- `/userdata/gateway/bin/sle_data_app`
- `/userdata/gateway/config/gateway_config.json`
- `/userdata/gateway/things_model`
- 测试工具和测试数据

### 2. 重启完整真实链路

```bash
bash app/Gateway/.claude/skills/run-gateway/driver.sh test-real-listen
```

这个命令会：

- 停止旧的 `gatewayd` 和 `sle_data_app`。
- 清理本轮运行日志。
- 启动 `gatewayd --config /userdata/gateway/config/gateway_config.json`。
- 等待 SLE IPC socket。
- 等待 MQTT 连接。
- 启动 `sle_data_app --mode real`。

### 3. 打开 SLE 专用监听助手

```bash
bash app/Gateway/.claude/skills/run-gateway/driver.sh watch-sle
```

显示扫描 candidate：

```bash
bash app/Gateway/.claude/skills/run-gateway/driver.sh watch-sle --scan
```

显示更多原始日志：

```bash
bash app/Gateway/.claude/skills/run-gateway/driver.sh watch-sle --raw
```

同时显示扫描和原始日志：

```bash
bash app/Gateway/.claude/skills/run-gateway/driver.sh watch-sle --scan --raw
```

## 日志怎么看

### gatewayd 主日志

```bash
adb shell "tail -f /userdata/gateway/data/log/gateway.log"
```

只看 SLE 拓扑消费结果：

```bash
adb shell "tail -f /userdata/gateway/data/log/gateway.log | grep -E 'SLE-TOPO|ST 0x05|ST 0x06|SLE-DATA'"
```

只看 MQTT 和上云状态：

```bash
adb shell "tail -f /userdata/gateway/data/log/gateway.log | grep -E 'cloud_connected|MQTT|publish success|publish failed'"
```

只看网络选路：

```bash
adb shell "tail -f /userdata/gateway/data/log/gateway.log | grep -E 'NET|selected|keep selected|preempt|dns realigned|ROUTE_DRIFT|CLOUD_UNREACHABLE'"
```

### sle_data_app 日志

真实运行输出：

```bash
adb shell "tail -f /tmp/sle_data_app.out"
```

SLE RX 明细：

```bash
adb shell "tail -f /tmp/sle_app.log"
```

SLE 底层 raw 日志：

```bash
adb shell "tail -f /tmp/sle_stack_raw.log"
```

### 同时看 gateway 和 SLE

```bash
bash app/Gateway/.claude/skills/run-gateway/driver.sh watch-real
```

说明：

- `watch-real` 是普通多文件 tail。
- `watch-sle` 是专用解析助手，会把 `05/06/DATA`、连接状态和 gateway 消费结果格式化显示。

## 上下行相关查看

### 上行：root 到 gateway

看 SLE 是否收到 root 发来的 `05/06/DATA`：

```bash
adb shell "grep '\\[SLE\\]\\[RX\\]' /tmp/sle_app.log /tmp/sle_data_app.out 2>/dev/null | tail -80"
```

只看拓扑和外设映射：

```bash
adb shell "grep '\\[SLE\\]\\[RX\\]' /tmp/sle_app.log /tmp/sle_data_app.out 2>/dev/null | grep -E '53 54 01 05|53 54 01 06' | tail -80"
```

看 gatewayd 是否消费或拒绝：

```bash
adb shell "grep -E 'ST 0x05|ST 0x06|SLE-TOPO|drop DATA|SLE-DATA' /userdata/gateway/data/log/gateway.log | tail -120"
```

### 下行：云命令到 root

看 gatewayd 命令处理：

```bash
adb shell "grep -E 'CMD|DOWNLINK|RPC|command|IpcCmdSender' /userdata/gateway/data/log/gateway.log | tail -160"
```

看 `sle_data_app` 下行发送：

```bash
adb shell "grep -E '\\[CMD\\]|ST-DOWNLINK|DOWNLINK|raw ST' /tmp/sle_data_app.out /tmp/sle_app.log 2>/dev/null | tail -160"
```

持续监听下行：

```bash
adb shell "tail -f /userdata/gateway/data/log/gateway.log /tmp/sle_data_app.out /tmp/sle_app.log | grep -E 'CMD|DOWNLINK|RPC|IpcCmdSender|ST-DOWNLINK'"
```

## 状态检查

### 进程

```bash
adb shell "ps | grep -E 'gatewayd|sle_data_app' | grep -v grep"
```

### IPC socket

```bash
adb shell "cat /proc/net/unix | grep -E 'gateway|sle_data|sle_cmd'"
```

预期能看到：

- `@var/run/gateway/sle_data.sock`
- `@var/run/gateway/sle_cmd.sock`

### MQTT 是否已连接

```bash
adb shell "grep 'cloud_connected' /userdata/gateway/data/log/gateway.log | tail -10"
```

### 当前网络与路由

```bash
adb shell "ip addr show eth1; echo ---; ip addr show wlan0; echo ---; ip route show default; echo ---; cat /etc/resolv.conf"
```

### 当前板端配置

```bash
adb shell "sed -n '1,120p' /userdata/gateway/config/gateway_config.json"
```

检查 DTU 总名单关键项：

```bash
adb shell "grep -n 'DTU_001\\|DTU_009\\|DTU_010\\|DTU_069\\|\\\"roots\\\"' /userdata/gateway/config/gateway_config.json"
```

## 手动启动备用命令

不使用 driver 时，可以手动启动。

停止旧进程：

```bash
adb shell "killall -9 gatewayd 2>/dev/null; killall -9 sle_data_app 2>/dev/null; sleep 1"
```

清理本轮日志：

```bash
adb shell "rm -f /tmp/gatewayd.log /tmp/sle_data_app.out /tmp/sle_app.log /tmp/sle_stack_raw.log /userdata/gateway/data/log/gateway.log"
```

启动 `gatewayd`：

```bash
adb shell "mkdir -p /var/run/gateway /userdata/gateway/data/log"
adb shell "nohup /userdata/gateway/bin/gatewayd --config /userdata/gateway/config/gateway_config.json >/tmp/gatewayd.log 2>&1 &"
```

等待 data socket：

```bash
adb shell "for i in \$(seq 1 30); do cat /proc/net/unix | grep -q '@var/run/gateway/sle_data.sock' && echo ready && exit 0; sleep 1; done; echo timeout; exit 1"
```

启动真实 `sle_data_app`：

```bash
adb shell "nohup /userdata/gateway/bin/sle_data_app --mode real >/tmp/sle_data_app.out 2>&1 &"
```

## 常见判断

### 看到很多相同 topo

如果 `rx_count` 和 ST `seq` 都在递增，说明 root 侧确实连续发了多帧，不是 gatewayd 重复消费。

```bash
adb shell "grep '\\[SLE\\]\\[RX\\]' /tmp/sle_data_app.out /tmp/sle_app.log 2>/dev/null | tail -30"
```

### 看到 RX 但 gateway 拒绝

看拒绝原因：

```bash
adb shell "grep -E 'ST 0x05 parse failed|ST 0x06 rejected|unknown DTU|no_valid_05_snapshot|drop DATA' /userdata/gateway/data/log/gateway.log | tail -80"
```

典型原因：

- `0x05` 第一行 root node_id 不在 `gateway_config.json` 的 DTU 总名单。
- `0x05` 中任意 DTU 不在总名单。
- `0x06` 来自的 root 没有先通过有效 `0x05`。
- `DATA` 的 `src_node_id` 没有有效 `0x06` 外设映射。

### gatewayd 没有收到 SLE

```bash
adb shell "ps | grep -E 'gatewayd|sle_data_app' | grep -v grep"
adb shell "cat /proc/net/unix | grep -E 'sle_data|sle_cmd'"
adb shell "grep -E 'IPC|connected to gatewayd|batch send|sle_data_app IPC client connected|receive error|disconnected' /tmp/sle_data_app.out /userdata/gateway/data/log/gateway.log 2>/dev/null | tail -120"
```

### MQTT 不上云

```bash
adb shell "grep -E 'NET|MQTT|cloud_connected|dns|route|selected|cannot reach cloud' /userdata/gateway/data/log/gateway.log | tail -180"
adb shell "ip route show default; echo ---; cat /etc/resolv.conf"
```

```bash
bash app/Gateway/.claude/skills/run-gateway/driver.sh test-real-listen
bash app/Gateway/.claude/skills/run-gateway/driver.sh watch-sle
```
